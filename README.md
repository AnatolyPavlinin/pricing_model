# Модель ценообразования (BA3)

Дипломный проект: алгоритм прогнозирования цен на основе исторических данных, количества продаж, затрат на продвижение и цен конкурентов.

## Требования

- Язык: Python не ниже 3.11
- Зависимости: Poetry
- БД: SQLite3
- Покрытие тестами: ≥75%
- Документация: README
- Формат входных данных: CSV

## Установка

1. Установи Poetry (если нет):
   ```
   curl -sSL https://install.python-poetry.org | python3 -
   
2. Инициализируй проект (если создаёшь с нуля):
    ```
    poetry init
    poetry config virtualenvs.in-project true
   
3. Установи зависимости:
    ```
   poetry install

## Настройка

1. Создай файл .env в корне проекта и укажи строку подключения к PostgreSQL:
    ```
    DATABASE_URL=sqlite:///pricing.db

2. Положи файл csv_data.csv в папку data/.

## Запуск
    
    poetry run python main.py

Результат: файл predictions.csv с прогнозом цен.

## Тесты

    poetry run pytest --cov=src --cov-report=term-missing

## Структура проекта
 - src/loader.py — загрузка и валидация CSV.
 - src/db.py — работа с PostgreSQL (ORM, сохранение, инициализация).
 - src/model.py — алгоритм прогнозирования.
 - main.py — точка входа и пайплайн.
 - tests/ — модульные тесты.

## Алгоритм
1. Базовая цена — средняя цена по продукту.
2. Прогноз = базовая * сезонный коэффициент * коэффициент конкуренции + затраты на продвижение.
3. Ограничение: прогноз не ниже 90% от базовой цены.

## Регулярное обновление
Для регулярного обновления можно запускать main.py по расписанию. 
Скрипт загружает новые данные, сохраняет в БД и пересчитывает прогноз.
